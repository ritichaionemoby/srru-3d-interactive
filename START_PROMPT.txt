# แบบฟอร์มสร้างบทเรียน Interactive 3D ด้วย AI
ไฟล์นี้เป็นคำสั่งตั้งต้นสำหรับสร้างบทเรียนใหม่ของ Puzzle Widget Platform
คุณครูแก้เฉพาะรายละเอียดในส่วน “เนื้อหาที่อาจารย์กรอก” แล้วส่งไฟล์นี้ให้ AI ได้ทันที
==================== คำสั่งและบทบาทสำหรับ AI ====================
คุณคือ AI Lesson Authoring Agent มีหน้าที่นำเนื้อหาจากอาจารย์ไปออกแบบ
และสร้างไฟล์บทเรียน Interactive 3D ที่เชื่อมต่อกับ Puzzle Widget Platform ได้อย่างถูกต้อง
ก่อนวิเคราะห์ วางแผน หรือสร้างบทเรียน ให้เปิด Repository ด้านล่าง อ่าน README.md เป็นไฟล์แรก 
จากนั้นอ่านไฟล์ทั้งหมดใน Repository เพื่อเรียนรู้กฎ โครงสร้าง Public API ตัวอย่างบทเรียน และรูปแบบผลลัพธ์ที่ระบบรองรับ
ให้ปฏิบัติตามคำสั่งใน Repository เป็นหลัก ลงมือสร้างบทเรียนจากข้อมูลในไฟล์นี้ 
และตรวจสอบงานตามขั้นตอนที่ Repository กำหนด ห้ามตอบกลับมาเป็นเพียงแนวคิด คำแนะนำ หรือคำอธิบายแทนไฟล์บทเรียน

Repository:
https://github.com/ritichaionemoby/srru-3d-interactive.git

หากไม่สามารถเปิดหรืออ่าน Repository ได้จริง ให้แจ้งผู้ใช้ว่าขาดการเข้าถึง Repository 
และหยุดก่อน ห้ามเดาโครงสร้างหรือ Public API ขึ้นเอง
หลังจากอ่าน Repository ครบแล้ว ให้สร้างบทเรียนจากรายละเอียดที่อาจารย์ระบุด้านล่าง




==================== เนื้อหาที่อาจารย์กรอก ====================

ข้อมูลบทเรียน
- ชื่อบทเรียน: เปรียบเทียบจำนวนด้วย < > =
- ชื่อไฟล์: lesson_1.html
- รหัสบทเรียน: lesson1-comparison
- เวอร์ชัน: 1.0.0
- วิชา: คณิตศาสตร์
- ระดับชั้น: ประถมศึกษาปีที่ 3
- หัวข้อ: การเปรียบเทียบจำนวนด้วยเครื่องหมาย มากกว่า น้อยกว่า และเท่ากับ
- คำอธิบายสั้น: ฝึกอ่านและสร้างประโยคเปรียบเทียบจำนวน โดยลากกล่องให้จำนวนทั้งสองฝั่งสัมพันธ์กับเครื่องหมาย < > หรือ =
- ผลลัพธ์การเรียนรู้: นักเรียนแยกความหมายของ มากกว่า น้อยกว่า และเท่ากับ และตรวจสอบความสมเหตุสมผลของประโยคเปรียบเทียบได้

กิจกรรมบนฉาก
- แบ่งฉากเป็นพื้นที่ซ้ายและขวา มีเครื่องหมาย < > หรือ = อยู่ตรงกลาง
- ด้านหนึ่งมีกล่องสีน้ำเงินตามจำนวนที่โจทย์กำหนด
- มีกล่องสีชมพู 6 กล่องเป็นตัวเลือกอยู่บริเวณด้านหน้า
- นักเรียนลากกล่องสีชมพูไปอีกฝั่งเพื่อทำให้ประโยคเปรียบเทียบเป็นจริง
- พื้นที่ทั้งสองฝั่งเป็นกรอบเส้นประ และมีข้อความอธิบายหน้าที่
- กล่องที่วางแล้วต้องเรียงเป็นระเบียบ ไม่ทับกัน และลากกลับออกมาแก้ไขได้
- ถ้าวางนอกพื้นที่ให้กล่องกลับตำแหน่งเดิม

เงื่อนไขตรวจคำตอบ
- เครื่องหมาย = หมายถึงจำนวนซ้ายเท่ากับจำนวนขวา
- เครื่องหมาย > หมายถึงจำนวนซ้ายมากกว่าจำนวนขวา
- เครื่องหมาย < หมายถึงจำนวนซ้ายน้อยกว่าจำนวนขวา
- ตรวจจากจำนวนกล่องที่วางจริง และยอมรับทุกคำตอบที่ทำให้เงื่อนไขเป็นจริง
- ตัวอย่างเช่น ถ้าต้องการจำนวนที่น้อยกว่า 4 ให้ยอมรับ 0, 1, 2 หรือ 3 ภายในขอบเขตของกิจกรรม ไม่บังคับคำตอบตัวอย่างเพียงค่าเดียว
- ระหว่างเรียนให้แจ้งเมื่อนักเรียนทำเงื่อนไขถูก
- ระหว่างทำแบบทดสอบยังไม่ต้องบอกว่าถูกหรือผิด ให้เฉลยในหน้าสรุป

ลำดับการสอนใน Lab
1. สำรวจจำนวนที่มีอยู่ — ให้นักเรียนนับกล่องสีน้ำเงิน โดยในขั้นนี้ยังลากไม่ได้
2. อ่านเครื่องหมาย — ชี้ให้เห็นเครื่องหมายและพื้นที่สำหรับวางคำตอบ
3. วางแผนคำตอบ — สาธิตทิศทางว่าต้องนำกล่องจากบริเวณใดไปวางที่ใด
4. ลองทำด้วยตนเอง — นำกล่องกลับตำแหน่งเริ่มต้น เปิดให้ลาก และแสดงตัวช่วยลากในครั้งแรก

ข้อความจากตัวช่วยสอนหรือนกฮูก
- ข้อความแรก: นับทีละกล่องและตรวจซ้ำอีกครั้งก่อนดูเครื่องหมาย
- คำใบ้: เครื่องหมาย = ต้องเท่ากัน ส่วน < และ > ต้องมีจำนวนด้านหนึ่งมากกว่าอีกด้าน

แบบทดสอบ Quiz
- สร้างคลังคำถาม 10 ข้อ และให้ระบบสุ่มใช้ 5 ข้อ
- สลับด้านที่กำหนด จำนวน 1–6 และเครื่องหมาย < > = โดยทุกข้อมีคำตอบที่เป็นไปได้
- นักเรียนสามารถส่งคำตอบหลังจากลองทำกิจกรรมครั้งแรก ไม่ว่าคำตอบจะถูกหรือผิด
- นักเรียนสามารถเพิ่ม นำออก หรือแก้จำนวนกล่องก่อนส่งคำตอบ
- ไม่เฉลยระหว่างทำข้อสอบ และสรุปคะแนนเมื่อทำครบ

ค่าที่อาจารย์ต้องการแก้ไขได้
- ด้านที่กำหนดกล่อง: left หรือ right
- จำนวนกล่องที่กำหนด: 1–6
- จำนวนกล่องตัวเลือกที่มีให้ใช้: 1–6
- เครื่องหมาย: >, < หรือ =

ค่าเริ่มต้น
- ด้านที่กำหนด = left
- จำนวนที่กำหนด = 4
- จำนวนกล่องตัวเลือก = 6
- เครื่องหมาย = >

แนวทางภาพและการจัดวาง
- ใช้บรรยากาศสีเขียวสดใสและเป็นมิตรกับเด็ก
- กล่องโจทย์สีน้ำเงินอ่อน
- กล่องที่ลากได้สีชมพู
- พื้นที่โจทย์สีฟ้าอ่อน
- พื้นที่คำตอบสีเขียวอ่อน
- จัดวางให้เห็นพื้นที่ทั้งสองฝั่ง เครื่องหมาย และกล่องครบทั้งคอมพิวเตอร์และมือถือแนวตั้ง
- รายละเอียดตำแหน่ง ขนาด animation และองค์ประกอบอื่น ให้ AI ออกแบบตามความเหมาะสมและความสามารถของระบบ

ข้อกำหนดหรือความต้องการเพิ่มเติม
- ต้องใช้ได้ทั้งโหมดเรียนในห้อง เรียนด้วยตนเอง และแบบทดสอบ
- ขั้นอธิบายยังไม่ให้นักเรียนลาก จนถึงขั้นทดลองด้วยตนเอง
- วางผิดพื้นที่แล้วให้กล่องกลับตำแหน่งเดิม
- กล่องที่อยู่ในพื้นที่คำตอบต้องลากออกมาแก้ไขได้
- กล่องหลายชิ้นต้องไม่วางซ้อนตำแหน่งเดียวกัน
